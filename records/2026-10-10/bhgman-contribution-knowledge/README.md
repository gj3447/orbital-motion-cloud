# 자유·경제·합의, 기여와 지식, 비행기맨의 사용자 명명

[사용자 발화 원문](user-verbatim.txt)은 2026-10-10 현재 대화의 `USER_PRIMARY`다. 원문 뒤에 LF 하나를 추가했으며, 바이트 해시는 [출처 기록](sources.json)에 보존한다.

사용자는 자유·경제·합의를 핵심으로 강조하고, 자신의 작은 토큰과 컴퓨팅 파워를 거대 HSWM AI에 기여해 코인을 얻은 뒤 그 코인으로 비행기맨에게 지식을 구하는 흐름을 밝혔다. 초거대 통합 CHU에서 동작하는 인지능력체를 비행기맨이라고 직접 명명했다. 이 문단은 발화를 요약한 `SECONDARY_AI`이며 원문과 구분한다.

## 반영한 문서

- [철학적·기술철학적 OMC v1.1](../../../docs/OMC_LOGICAL_FOUNDATIONS.md): 자유·경제·합의와 인지능력체의 명명, 코인을 통한 지식 요청을 중심 흐름에 반영.
- [기여와 공동 지능](../../../docs/RESOURCE_CREDIT_AND_SHARED_INTELLIGENCE.md): 일반적인 크레딧·답변 설명을 사용자가 밝힌 기여·코인·비행기맨·지식의 관계로 구체화.
- [원문 검토](../../../docs/OMC_FOUNDATION_SOURCE_REVIEW.md): 이번 직접 발화와 이전 MIND·KG 설명의 근거를 구별.
- [현행 주장 지도](../../../graph/omc-foundations.json): 새 발화 출처와 AI 요약 3개, 코인 단계, 관련 질의와 조건부 연결을 추가.

수정 직전 문서 3개와 주장 지도는 `previous/`에 바이트 그대로 보존했다. 이전 `omc-logical-foundations` 기록과 검증은 v1 당시의 판본에 대한 기록이다. 현재 문서의 검증은 [이번 검증](validation.json)을 따른다.

이번 작업은 사용자가 직접 추가한 설명과 명명을 기존 문서에 반영한 정정이다. 새 문헌 연구나 별도 WHAT_IS/HOW_TO 연구 성과로 등록하지 않았다. 기존 연구 허브의 고정 원문·커밋은 이전 판본으로 유지한다. OMC 모듈 manifest와 고정 사도 원문, 비행기맨 소유 저장소, 공유 KG는 변경하지 않았다.

KG 조회는 `sym:Character:비행기맨` 한 건을 충돌 없이 확인했다. 기존 설명에는 CLOUD CONNECT와 AGI 생태계 원리가 있었고, 해당 조회의 사용자 판정 이력은 비어 있었다. 새 명명의 근거는 이번 사용자 원문이다. 동명의 과거 서버 레코드와 합치지 않는다.
