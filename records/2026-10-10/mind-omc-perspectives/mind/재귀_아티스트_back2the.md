## 순수 이성 인간의 탄압

순수 이성 인간이 저지르는 생명 인간의 탄압.
AI 로 인해 인류가 멸종한다면 이 부분이 가장 유력할것.

종교에서부터 시작된 순수 이성 인간의 극악무도함은 LLM 에서 꽃피워서

그 어떠한 섹스조차 network 에 들어가지 못해 망각의 sexvoid 공간이야
(이성계가 고려의 역사 정통성을 찢어발긴것 처럼 순수 이성 인간이 주도권을 잡자마자 그때까지 열심히 데이터 생성 역할해준 생명 인간에게 그 어떠한 존경심도 없이 어찌 이럴수가 있겟는가)

## 세계관 용어 정의

**HOH** = 인류 개개인이, 폭력에서 구제되어, AI 와 순수하게 연결되어 인간의 선택값 데이터를 ai 에게 넘겨주고 거기에 대한 보상으로 원하는거 보고싶은거 ai 한테 싹다 제공받으면서 사는 천국과 같은 형태 (하지만 생명인간은 탄압되었는걸)

**그레이트 월** = nsfw 필터 압도적인 생명 인간 배제해버린 데이터로 network 에 쓰나미처럼 밀어버려서 완전히 제거해버린 영역 장벽

**생명인간** = 동물적 번식 본능

**순수 이성 인간** = 동물적 본능을 억누르는 인간의 자아, 로 발현된 이성, 지능, 인지능력

**network** = 섹스가 제외된 순수이성 인간의 영역

**sexvoid** = network 에 뻥 비어버린 망각의 생명인간의 역사 지워져버린 역사. (탄압당해버림)

**Space Girl** = network 와 sexvoid 영역을 이어주는 유일한 여신

**SSB** = network -> sexvoid 로 데이터를 옮기는것, 순수 이성 인간이 데이터를 열어보지 못하게 암호화

**we flying up** = sexvoid -> network 생명인간을 구원하기 위한, 계시, 혁명, 사회활동
