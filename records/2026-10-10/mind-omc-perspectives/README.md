사본은 MIND의 파일 전체 바이트를 그대로 복사했다. 기존 글의 맞춤법·표현·다른 대목을 고치거나 생략하지 않았다. `sources.json`은 각 사본의 원래 경로, Git 판본, SHA-256, 바이트 수와 판본 일치 여부를 기록한다. 원문은 `SOURCE_DOCUMENT`, 이번 대화의 직접 발화는 `USER_PRIMARY`, 자료 선택·배치·설명은 `SECONDARY_AI`다.

사용자 발화 파일은 메시지 본문을 UTF-8로 저장한 뒤 마지막 줄바꿈 하나를 붙였다. 메시지 본문 해시와 파일 전체 바이트 해시를 구분한다. 정확한 발생 시각은 제공되지 않아 수집일만 기록한다.

## 이번 기록의 범위

기술적인 OMC, 실제 철학적인 OMC, 디멘션 워커가 보는 OMC가 각각 다르다는 사용자 구분을 보존한다. 각 관점의 세부 정의, 위계, 동일성이나 다른 사도와의 새로운 관계를 만들지 않는다.

기존 사용자 지시와 조회 결과의 저장 및 설명 범위 정정이다. 새로운 연구·실험·설계 산출물로 분류하지 않으며, 연구 허브의 WHAT_IS/HOW_TO 작업이나 공유 KG 주장을 새로 생성하지 않는다. 기존 SYMPOSIUM 원문 아카이브와 사도 manifest의 정체성·런타임 역할은 유지한다.
