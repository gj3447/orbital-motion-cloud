기준 연산 단위, 기여 검증, 보상과 발행의 구분, 미래 공급과 이용 의무, 사건 이력과 정산 확정, 가격·정책 변경, 공급 부족, 후속 실험을 HOW_TO 연구 설계 v0.1에 담았다. 사용자가 명명한 비행기맨과 자유·경제·합의를 출발점으로 삼는다. 연구 원문과 사용자 원문은 분리했다.

기존 일반 `coin`, `infrastructure-orchestration`, `metahumotonic-apostles` 주제를 조회하고 목적을 비교했다. 이번에는 컴퓨팅 구매력 안정화와 시간 이력에 기반한 정책 발전이라는 독립 질문을 분리했다. 허브의 WHAT_IS/HOW_TO 쌍 정책으로 WHAT_IS 초기 골격도 생성되었지만, WHAT_IS 연구 산출물을 만들어 넣지는 않았다.

새 저장소는 20TB 공유 경로의 로컬 독립 Git 저장소다. GitHub 원격 저장소 생성은 수행하지 않았다. 출처 무결성·문서 링크·산술 예시 검사는 연구 저장소에 기록하며, 실제 경제 안정성 실험은 아직 수행하지 않았다.

최초 갱신은 SSD 여유 부족으로 중단되었다. 공간 회복 후 동일 요청을 재개하여 2026-10-10 16:00 UTC에 관리형 실행기가 정상 종료했고, 최종 render/check와 공식 `COMPLETE` 상태를 확인했다. 원문·기존 커밋·이전 중단 기록은 그대로 보존했다.

[최종 허브 게시 기록](../hardware-adaptive-placement/publication.json): 관련 테스트 25개 통과 후 허브 커밋 `943b71a`를 기존 private main에 반영했다.
