# Orbital Motion Cloud

Position 8 apostle module. This repository preserves the source-attested identity and English label; it does not define abilities, behavior, or an agent runtime.

Identity and source pins are in `APOSTLE_MODULE.json`. The dashboard owner is [METAHUMOTONIC_DASHBOARD](https://github.com/gj3447/METAHUMOTONIC_DASHBOARD); its `graph/apostles.json` records the roster selection.

```sh
python3 cli.py identity
python3 cli.py show
python3 cli.py check
```

`docs/WHAT_IS.md` holds identity/source context. `docs/HOW_TO.md` holds the safe maintenance procedure.

## Content index

`APOSTLE_CONTENT.json` lists every archived source file, byte digest, and source revision. The source archive begins at `sources/SYMPOSIUM/METAHUMOTONIC/ORBITAL_MOTION_CLOUD/`; it is `SOURCE_DOCUMENT`. This README and `docs/` are `SECONDARY_AI` guides.
